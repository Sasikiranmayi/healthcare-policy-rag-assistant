# Dataset Overview

This dataset supports a conversational AI assistant designed to answer questions about **public healthcare policy and operational guidance**.

The primary source is an official NHS England planning guidance PDF, complemented by structured Markdown documents that provide context, definitions, and safety boundaries.

## Included Sources
- NHS England 2025–26 Priorities and Operational Planning Guidance (PDF)
- Supporting Markdown documents covering NHS structure, terminology, and scope

## Purpose
The dataset is intentionally scoped to:
- Enable accurate, grounded answers
- Support multi-turn, conversational queries
- Avoid clinical, diagnostic, or personalised medical advice

All responses generated by the assistant must be grounded strictly in the provided doc
